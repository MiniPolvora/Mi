# 🌌 O Céu que Conta Histórias

Um projeto interativo de ciência desenvolvido pelos alunos do 7º ano da EMEF Padre Pedro Piccoli para a Mostra Científica 2026.

## Projeto

Este projeto apresenta um mapa interativo das constelações visíveis nos hemisférios Norte e Sul, combinando astronomia, mitologia e cultura.

### 🎯 Objetivo

Apresentar a importância das constelações para a ciência, história e cultura através de uma experiência interativa.

## 📱 Como Usar

1. **Mapa Interativo** (`index.html`):
   - Clique no botão "Hemisfério" para alternar entre os hemisférios Sul e Norte
   - Use o mouse para arrastar o mapa
   - Role o mouse para fazer zoom in/out
   - Clique em uma constelação para ver informações

2. **Dados & Curiosidades** (`dados.html`):
   - Visualize informações sobre o projeto
   - Conheça os autores e orientadores
   - Leia o resumo científico
   - Explore as constelações em destaque
